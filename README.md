# PUJA Handmade Website

A simple business website with a password-protected admin panel for adding and managing handmade products.

## Features
- Public business homepage
- Product gallery with image support
- Password-protected admin area
- Add and delete products
- Product data stored in browser localStorage

## Default admin password
- `puja123`

## How to use
1. Open `index.html` in a browser to view the public website.
2. Open `admin.html` to log in to the admin panel.
3. Enter the password: `puja123`
4. Add products with name, category, price, description, and image.

## Notes
- This is a static frontend project and does not need a backend server.
- For a live website, deploy this project on GitHub Pages or any static hosting service.
- To publish on GitHub Pages:
  1. Go to GitHub repository settings.
  2. Open Pages.
  3. Choose the main branch and root folder.
  4. Save and wait for the site to publish.

## Files
- `index.html` - public business page
- `admin.html` - admin login and product management page
- `styles.css` - styling and layout
- `script.js` - product logic and admin authentication

## Customize
- Update business name, contact details, and colors in the HTML/CSS files.
- Replace example products with your actual handmade items.
